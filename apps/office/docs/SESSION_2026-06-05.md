# Session Log — 2026-06-05

> Everything built, changed, and configured on this date. Covers the **Jelly** skill runtime (OpenClaw replacement), Denizen rewiring, LM Studio dual-model tuning, and NPC provider rebalancing.

---

## Executive summary

Denizen now runs NPC skills through **Jelly** 🪼 — a Denizen-native skill runtime — instead of dispatching through the OpenClaw gateway. OpenClaw skill scripts were **vendored into the repo** under `apps/office/jelly/`. Sidecar services (Supabase bridge, BrowserClaw) were copied and wired to `~/.denizen/` paths. OpenClaw gateway is **off by default**. NPC model load was **rebalanced** across two LM Studio slots (Ministral 14B + Gemma 4 2B).

**Test status at end of session:** 470 tests passing (9 new Jelly tests in `tests/jelly.test.js`).

## 1. Jelly — Denizen-native skill runtime

### What it replaces

Previously, `server.js` contained ~460 lines of inline OpenClaw skill dispatch (subprocess spawning, path resolution, gateway proxy). That logic is now centralized in Jelly.

OpenClaw is no longer required at runtime. The gateway HTTP/WS proxy is disabled unless explicitly enabled.

### Branding

| Constant | Value |
|----------|-------|
| Name | Jelly |
| Emoji | 🪼 |
| Tagline | The jellyfish way. |
| Log tag | `[Jelly 🪼]` |
| Factory | `createJelly()` in `jelly/index.js` |

### Core modules

| File | Purpose |
|------|---------|
| `jelly/index.js` | `createJelly()` — wires registry, executor, intents |
| `jelly/meta.js` | Branding constants (`JELLY`) |
| `jelly/paths.js` | `~/.denizen/` home, vendor script paths, browser flags |
| `jelly/config-loader.js` | Loads `config/jelly.json`, env overrides |
| `jelly/config-provider.js` | Shared config access for Denizen modules |
| `jelly/skill-registry.js` | Native + vendor + optional legacy skill registration |
| `jelly/skill-executor.js` | In-process and subprocess skill execution |

### Config

Primary config: `apps/office/config/jelly.json`

Fallback chain (in `config-loader.js`):
1. `apps/office/config/jelly.json`
2. `~/.openclaw/openclaw.json` (legacy)
3. `~/.denizen/jelly.json`

Key fields:
- `supabase.url` / `supabase.bridgeUrl`
- `browser.browserclawUrl`
- `tools.web.search` (Brave API key)
- `models.providers` (LLM endpoints)

### Home directory

Jelly state lives under **`~/.denizen/`** (not `~/.openclaw/`):

```
~/.denizen/
├── browser/          # Lucy browser session, lucy-close.flag
├── canvas/           # Canvas render output
└── workspace/        # Agent workspace files
```

Override with `JELLY_HOME` env var.

### Skill dispatch flow

```
NPC think() → action: run_skill
       ↓
server.js → runNpcSkill(npcName, skill, params)
       ↓
jelly.runSkill() → SkillExecutor
       ↓
  ┌─ native skill → in-process run()
  └─ vendor skill → subprocess spawn
       ↓
npcBrains.injectSkillResult() → next think cycle
```

Special routing: Lucy `job-scraper` / `job-applier` → `job-pipeline` native skill.

Intent classifiers still live in `src/openclaw-dispatch.js` (re-exported as `jelly.intents`). Rename to `jelly-intents.js` is planned but not done.

### LM Studio UI settings

1. Load **both** models simultaneously (green/active on each)
2. Set **Parallel = 2** on each (match `LM_STUDIO_PARALLEL=2`)
3. VRAM budget: ~9 GB (Ministral) + ~4 GB (Gemma) ≈ 13 GB on 16 GB GPU

### Recommended throttle settings (optional)

If the queue backs up with 16+ NPCs thinking every 2–4 minutes:

```env
LM_STUDIO_PARALLEL=1
DENIZEN_THINK_MIN_MS=240000
DENIZEN_THINK_MAX_MS=360000
DENIZEN_GLOBAL_THINK_GAP_MS=12000
```

### Known Gemma issue

Roki (and other fast-tier NPCs) may return empty chat when Gemma burns all tokens on internal reasoning (`finish_reason: length`). Workarounds:
- Disable reasoning/thinking for Gemma in LM Studio UI
- Move affected NPC back to `lmstudio` in their `SOUL.md`
- Bump chat `maxTokens` for fast-tier (code change not yet done)

## 6. Real work vs roleplay

### Why NPCs show `skill: null`

The think-loop prompt (`npc-brains.js` + `prompt-tuning.js`) intentionally discourages `run_skill` on most cycles. Combined with:

```env
DENIZEN_RUN_SKILL_COOLDOWN_MS=900000   # 15 min between skills
DENIZEN_RUN_SKILL_MAX_PER_WINDOW=1
```

NPCs often return `{"action": "work", "skill": null, "save": "..."}` — narrating work without invoking Jelly.

### How to trigger real work

| Method | Example |
|--------|---------|
| Player chat | `hey lucy search remote AI jobs` |
| Directive API | `POST /api/assign-directive` |
| Lower cooldown | `DENIZEN_RUN_SKILL_COOLDOWN_MS=300000` |
| Real work mode | `DENIZEN_REAL_WORK_MODE=true` (already on) |

### Work mode env vars (current)

```env
DENIZEN_ECONOMY_MODE=false
DENIZEN_REAL_WORK_MODE=true
DENIZEN_AUTO_CLAIM_SPRINT=true
DENIZEN_RUN_SKILL_COOLDOWN_MS=900000
DENIZEN_RUN_SKILL_MAX_PER_WINDOW=1
```
