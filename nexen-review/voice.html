Speak your next move.

Choose Command for local navigation and safe numbered targets, or Ask JARVIS to ask about your situation and selected photo. The visible pointer stays inside NEXEN; it does not move the Windows mouse.

Uses the same local interpreter and safe action rules. No microphone needed. The selected Command / Ask JARVIS mode also applies here.

A command or a question.

Ask JARVIS mode sends questions to the problem page and uses its selected photo/model. A successful draft is read with an available local device voice. Questions are never interpreted as navigation commands in this mode.

Choose Record command, speak, then Finish & transcribe. Recording ends automatically after 20 seconds and is sent once. Stop / discard cancels capture and pending browser actions.

“Open money”Navigate to the Money Engine.
“Open next step”Choose a specific task before task commands.
“Scroll down”Scroll the current NEXEN view.
“Show numbers”Label visible safe links and workspace controls.
“Focus 3” / “Click 3”Use an existing numbered target; forms and transactions are excluded.
“Read current task”Send a read request to the selected task on Next step.

On Next step, “do current” or “complete current” is handed to that page's selected-task controller. Voice control does not choose a task, execute a workflow or mark anything complete by itself.

When microphone access is denied or local transcription is unavailable, the typed field remains available. Changing tabs, leaving the page or minimizing the voice panel stops capture.

Local audio processing. This browser captures mono audio and sends signed 16-bit PCM at 16 kHz to the local NEXEN transcription endpoint. It does not use browser cloud speech recognition or save an audio file. A request already submitted may finish on the local server after you press Stop; its returned command is ignored. No listening starts until you choose Record command.
