Step 6 — After export

Merge sprite_cuts.json into data/furniture_catalog_openplan.json, then placements from editor X into the same file. Regenerate the blueprint:

cd denizen && npm run blueprint:build
cd denizen && npm run catalog:wire-editor
cd denizen && npm run validate:catalog

Master catalog warning? The 49k singles are a reference index — not meant to be placed. catalog:wire-editor adds curated defs to the editor without touching your 89 placements.
