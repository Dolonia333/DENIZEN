Download Denizen Desktop

Run Denizen on your machine with real hardware profiling, the setup wizard, and optional compute contribution.

Download for Windows

Getting started:

  1. Download and run Denizen-Setup.exe.
  2. Launch Denizen from the Start menu or desktop shortcut.
  3. Complete the setup wizard and link your Denizen account (session ID from browser login).
  4. Choose permission level and opt in to compute if you want this machine to contribute.
  5. Open Denizen — your agent syncs capabilities with your account.

Installer path: /desktop/dist/Denizen-Setup.exe. Build with npm run build:win in the desktop folder.
