Getting started:

  1. Get an invite link from your team (or join with a team code at the city login screen).
  2. Create your account — username, email, and password.
  3. Download Denizen for your computer using the button above.
  4. Launch Denizen — it opens your browser to log in and pair this computer automatically.
  5. Add City Power when you're ready, or leave it off and decide later.

Windows: run Denizen-Setup.exe from Downloads. If SmartScreen warns you, choose More info → Run anyway.

macOS: open Denizen.dmg, drag Denizen into Applications, then open it from Applications. If macOS says the app is from an unidentified developer, open System Settings → Privacy & Security and click Open Anyway.

Linux: chmod +x Denizen.AppImage then run the AppImage.

Windows 10+, macOS 11+, or a modern 64-bit Linux distribution. Installers are served from your city server mirror or GitHub latest. If a file 404s, Talk to Zion on Discord or build from desktop/.
